# Monster Content

Use this skill only for adding or modifying monster definitions, stats, abilities, drops, or monster-specific encounter content.

1. Read `docs/game-design/monsters.md` and `docs/game-design/combat.md`.
2. Confirm the request against monster canon; when one monster is requested, change only that monster.
3. Keep monster data, encounter composition, and visual assets independent.
4. Validate affected resources and encounter references.
