# World Content

Use this skill only for towns, travel, dungeons, reputation, rumors, or world progression.

1. Read `docs/game-design/world.md`, `core-rules.md`, and `endings.md` as applicable.
2. Inspect current progression data before editing and preserve location order and established rules.
3. Put unlocks, reputation, rumors, and outcomes in world/progression data rather than UI.
4. Validate affected world rules and Godot errors.
