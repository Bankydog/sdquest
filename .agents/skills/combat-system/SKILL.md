# Combat System

Use this skill only for battle rules, turns, actions, skills, status effects, encounter resolution, or battle state.

1. Read `docs/game-design/combat.md`, `core-rules.md`, and relevant architecture guidance.
2. Inspect existing battle-domain code and content before editing.
3. Keep rule/state changes independent of scenes and UI; use data definitions and explicit randomness inputs.
4. Validate the affected rules and inspect Godot errors.
