# Endings

The ending system supports these ten categories:

1. Defeat Demon King
2. Defeat subordinate / alternate boss path
3. Betrayal
4. Defeat / failure
5. Become Demon King
6. Escape
7. Balance ending
8. Humans were wrong
9. Villager ending
10. Killed ending

Ending eligibility should be evaluated from progression, reputation, rumors, party state, and decisive choices through data-oriented world/end-state rules. UI should present an ending decision, never define it.

Exact prerequisites, priority when several categories are eligible, and individual ending scenes are not yet canon.
