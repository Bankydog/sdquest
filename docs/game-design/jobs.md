# Jobs

Jobs define reusable character progression and combat capabilities. A job definition is distinct from both a recruitable character definition and a runtime party member.

## Data expectations

A job should be content data that can reference its skills, stat rules, progression, and permitted equipment without depending on battle UI or a particular visual asset. Runtime changes such as current HP, learned state, equipment, and temporary effects belong to the party-member state.

## Canon status

No named jobs, job-switching rules, stat formulas, skill lists, or equipment restrictions are established yet. Do not introduce them as canon without an explicit design decision.
